# Política de Segurança

## Versões suportadas

A primeira release formal (`v1.0.0`) já foi publicada (ver `CHANGELOG.md` e a tag `v1.0.0` no
repositório). Apenas o estado mais recente da branch `master` recebe correções de segurança;
não há suporte a releases anteriores a `v1.0.0`.

## Como reportar uma vulnerabilidade

**Não abra uma issue pública para relatar uma vulnerabilidade de segurança.** Issues públicas
no GitHub são visíveis a qualquer pessoa antes de existir uma correção.

Em vez disso, envie um e-mail diretamente para:

- **padilhars@gmail.com**

Inclua, na medida do possível:

- Uma descrição do problema e seu impacto potencial.
- Passos para reproduzir (versão do Moodle, versão do plugin, configuração relevante).
- Se souber, uma sugestão de correção.

Você receberá uma confirmação de recebimento em até 5 dias úteis. Pedimos que o problema não
seja divulgado publicamente até que uma correção esteja disponível.

## Escopo

Esta política cobre apenas o código deste plugin (`local_a11y`). Vulnerabilidades no Moodle
core ou em plugins de terceiros (ex.: `local_vlibras`) devem ser reportadas aos respectivos
mantenedores.
