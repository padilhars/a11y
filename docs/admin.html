Sobre este documento

Este documento foi elaborado a partir do material institucional consolidado do plugin (estudos, código-fonte, arquivos de idioma e exploração ao vivo do ambiente de demonstração). Trechos sem evidência suficiente estão sinalizados como "[INFORMAÇÃO A VALIDAR]" e devem ser confirmados pela equipe responsável antes da publicação oficial.

1. Sobre este guia

Este guia é destinado a equipes de TI e administradores do Moodle responsáveis por instalar, configurar e manter o plugin A11y for Moodle. Ele traz comandos, nomes técnicos de configuração e procedimentos operacionais que a Documentação Executiva e o Manual do Usuário deliberadamente não trazem, por serem voltados a públicos não técnicos.

Este guia não substitui a documentação técnica gerada automaticamente a partir do próprio código-fonte do plugin (Seção 11), que é a referência mais detalhada e a que mais rapidamente reflete mudanças futuras no código.

2. Requisitos técnicos

Versão do Moodle Branch 502 (Moodle 5.2) — única versão efetivamente testada e confirmada em funcionamento.
Versão do PHP 8.2 ou superior. A integração contínua (CI) do projeto testa especificamente as versões 8.3 e 8.4.
Banco de dados CI testado contra PostgreSQL e MariaDB.
Espaço em disco Aproximadamente 19 MB — o pacote cresceu de forma relevante após o modelo e o executável da biblioteca MediaPipe (usados pela Navegação por Face) passarem a ser empacotados localmente, em vez de carregados de um CDN externo.
Extensões PHP pgsql, zip, gd, mysqli — usadas no workflow de referência de integração contínua do próprio projeto.
Permissões de arquivo Padrão de plugins Moodle: leitura pelo usuário do servidor web sobre o diretório do plugin.
Atenção ao requisito real de versão

O plugin cita "Moodle 5.0 ou superior" em alguns pontos de forma ampla, mas o valor técnico configurado em version.php corresponde a uma build que a série 5.0 real do Moodle nunca alcança. Testes de integração contínua contra o núcleo oficial do Moodle 5.0 mostram que a instalação é recusada ("pluginrequirementsnotmet"). Antes de planejar a instalação, confirme que o ambiente-alvo roda efetivamente a branch 5.2.

3. Preparação pré-instalação

Checklist antes de iniciar:

  • Confirmar a versão exata do Moodle em uso (Administração do site → Notificações, ou o valor de $CFG->version).

  • Confirmar a versão do PHP em uso no servidor.

  • Fazer backup do banco de dados e dos arquivos do Moodle antes de instalar qualquer plugin — prática padrão, não específica deste plugin.

  • Providenciar acesso de escrita ao diretório local/ do Moodle (ou public/local/, em instalações que já usam a nova estrutura de webroot introduzida a partir do Moodle 5.0).

  • Se a instituição já utiliza o plugin local_vlibras, ter isso em mente para a etapa de configuração de Integrações (Seção 5) — a instalação do A11y não exige o VLibras, mas pode integrar-se a ele se presente.

4. Instalação passo a passo

Passo 1 — Obter o pacote

Obtenha o arquivo local_a11y.zip, ou o código-fonte diretamente do repositório, junto à equipe responsável (CPTED).

Passo 2 — Extrair no diretório correto

# Layout clássico (instalações sem a nova estrutura public/)
unzip local_a11y.zip -d /caminho/para/moodle/local/
# Layout Moodle 5.0+ com webroot dentro de public/
unzip local_a11y.zip -d /caminho/para/moodle/public/local/

O diretório resultante deve se chamar a11y, ficando em <moodleroot>/local/a11y (ou <moodleroot>/public/local/a11y, conforme o layout da instalação).

Passo 3 — Completar a instalação

Opção A — pela interface: acesse Administração do site → Notificações. O Moodle detecta o plugin novo automaticamente e apresenta a tela padrão de instalação.

Opção B — por linha de comando:

php admin/cli/upgrade.php --non-interactive

Passo 4 — Confirmar

O botão de acessibilidade deve aparecer em qualquer página do Moodle, para qualquer pessoa usuária — inclusive visitantes não autenticados, por padrão (configurável na Seção 5).

5. Configuração administrativa completa

Caminho: Administração do site → Plugins → Plugins locais → Acessibilidade (A11y). As configurações estão organizadas em até cinco grupos — o de Integrações só aparece se o plugin local_vlibras estiver instalado.

Geral

Configuração Tipo · padrão O que faz
local_a11y/enabled Checkbox · ativado Ativa/desativa o botão e o painel em todo o site.
local_a11y/showforguests Checkbox · ativado Exibe o botão para usuários não autenticados.
local_a11y/excludedpages Textarea · vazio Um padrão de URL por linha (aceita * como coringa); o plugin não carrega nas páginas correspondentes.
local_a11y/enabledfeatures Multicheckbox · todas ativadas Escolhe quais opções de acessibilidade ficam disponíveis às pessoas usuárias.

Integrações (condicional a local_vlibras estar instalado)

Configuração Tipo · padrão O que faz
local_a11y/integratevlibras Checkbox · desativado Quando ativado, oculta visualmente o botão próprio do VLibras e move o acesso para a opção "Libras (VLibras)" deste plugin. O script do VLibras continua carregando normalmente — só a exibição do botão muda.
Observação

Se o VLibras estiver instalado e ativo, mas esta integração estiver desligada, o painel de administração exibe um aviso de possível sobreposição visual entre o botão do VLibras e o botão deste plugin, quando as posições configuradas de cada um coincidirem.

Botão Flutuante (FAB)

Configuração Tipo · padrão O que faz
local_a11y/fabposition Select · bottom-right Canto da tela: bottom-right, bottom-left, middle-right ou middle-left.
local_a11y/fabicon Select · default Ícone do botão: default (ícone próprio, Ionicons) ou un (ícone de acessibilidade da ONU).
local_a11y/fabshape Select · circle Formato do botão: circle ou square.

Painel

Configuração Tipo · padrão O que faz
local_a11y/panelformat Select · popover Formato em telas de desktop: popover, drawer ou modal. Em celulares e tablets pequenos, sempre abre como drawer, independentemente deste valor.
local_a11y/density Select · regular Densidade visual das linhas de opção: compact, regular ou comfortable.
local_a11y/showprofiles Checkbox · ativado Exibe a seção de perfis prontos no painel.
local_a11y/footertext Editor HTML · vazio Texto customizado no rodapé do painel. Vazio usa a mensagem padrão: "Desenvolvido com ❤️ pela UFPel, para você."

Cores

Configuração Padrão O que colore
local_a11y/accent #3b82f6 Cor de acento do botão e do painel.
local_a11y/highlighttitlescolor #eab308 Cor usada por "Destacar Títulos".
local_a11y/highlightlinkscolor #3b82f6 Cor usada por "Destacar Links".
local_a11y/highlightbuttonscolor #f97316 Cor usada por "Destacar Botões".
local_a11y/readingguidecolor #3b82f6 Cor da linha usada por "Guia de Leitura".

6. Capabilities e permissões

O plugin define uma única capability:

local/a11y:view
captype: read
contextlevel: CONTEXT_SYSTEM
archetypes: guest, user, frontpage, student, teacher, editingteacher, manager — todos CAP_ALLOW por padrão

Não existe capability própria de configuração — a tela de administração (settings.php) é protegida pelo mecanismo padrão do Moodle para configurações de site (moodle/site:config), como qualquer outro plugin.

Observação

Uma capability local/a11y:configure existiu em versões anteriores do plugin, mas foi removida após uma auditoria de segurança e código morto constatar que ela nunca era, de fato, verificada em nenhum lugar do código — atribuí-la a um perfil não tinha efeito algum.

7. Validação pós-implantação

Checklist sugerido após instalar ou atualizar:

  • O botão de acessibilidade aparece em uma página de curso, tanto logado quanto deslogado (se showforguests estiver ativado).

  • Um perfil e uma opção individual aplicam corretamente ao serem selecionados.

  • A preferência persiste após recarregar a página (F5).

  • Para um usuário autenticado: a preferência persiste após logout e login novamente.

  • Se a instituição integra o VLibras: testar especificamente a opção "Libras (VLibras)".

  • Testar em ao menos um navegador baseado em Chromium (para Comandos por Voz) e confirmar que outros navegadores exibem a mensagem de indisponibilidade, em vez de falhar silenciosamente.

8. Atualização e manutenção

Para aplicar uma nova versão: substitua os arquivos do plugin pela versão nova e repita a Seção 4, Passo 3 (Administração do site → Notificações, ou o comando de upgrade via CLI).

Comandos úteis para quem for alterar o código-fonte do plugin:

# Recompilar os módulos JavaScript (AMD) após editar amd/src/*.js
npx grunt amd --root=local/a11y
# Rodar a suíte de testes automatizados (PHPUnit)
vendor/bin/phpunit --configuration local/a11y/phpunit.xml
# Rodar os testes de comportamento (Behat), com tag do plugin
vendor/bin/behat --tags="@local_a11y"

9. Resposta a incidentes e reversão

Procedimento documentado no próprio repositório do plugin (MAINTENANCE.md):

Passo 1 — Desativar sem remover código: Administração do site → Plugins → Plugins locais → A11Y for Moodle → Desativar (ou, via CLI, ajustar a configuração local_a11y/enabled). Reversível instantaneamente, sem tocar em arquivos.

Passo 2 — Se a causa for uma mudança de código recente: reverter para o commit anterior no repositório (git revert do commit problemático — não git reset --hard, para preservar o histórico) e reimplantar o diretório local/a11y a partir dele.

Limitação

Não existe hoje um ambiente de homologação separado do ambiente de produção para este plugin — risco já registrado no Plano de Continuidade e Sucessão Técnica. Redobre a cautela ao testar qualquer mudança diretamente em produção, e considere testar primeiro em um curso de uso restrito antes de expor a mudança a toda a instituição.

10. Solução de problemas técnicos comuns

Problema técnico Causa possível Ação
Plugin não aparece após a instalação Cache do Moodle desatualizado. Purgar todos os caches: Administração do site → Desenvolvimento → Purgar caches.
Erro "pluginrequirementsnotmet" durante a instalação Versão do Moodle abaixo da exigida — inclusive a série 5.0 real. Confirmar que a instância roda especificamente a branch 5.2 (ver Seção 2).
Opção "Libras (VLibras)" não aparece, mesmo com o VLibras instalado Integração não ativada nas configurações deste plugin. Ativar local_a11y/integratevlibras em Configurações → Integrações (Seção 5).
Botões do VLibras e do A11y sobrepostos visualmente Posições configuradas coincidentes, com a integração desligada. Ativar a integração (oculta o botão nativo do VLibras), ou ajustar a posição de um dos dois.
Ícone ou cor customizados não aplicam Cache de CSS do Moodle. Purgar caches; confirmar formato hexadecimal válido no campo de cor.
Comandos por Voz não funciona em um navegador específico Reconhecimento de voz via Web Speech API disponível apenas em navegadores baseados em Chromium. Esperado — o plugin já detecta e avisa a indisponibilidade; testar em navegador Chromium para confirmar que a função em si funciona.
