(inner, constant) MOBILE_BREAKPOINT_QUERY :string

Below this breakpoint the panel is always drawer-style, regardless of the admin-configured local_a11y/panelformat - mirrors the CSS override in styles.css (Styleguide 5.2.1), which is what actually forces the drawer geometry; this is only here so the open/close *behaviour* (overlay, FAB hiding) matches those visuals even when the configured format is popover or modal. Moodle Boost's own nav-collapse breakpoint, since below that there isn't room to float a centered/anchored panel either way.
