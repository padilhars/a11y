(inner) freezeGif(img) → {void}

Freeze a single GIF on its currently-displayed frame by drawing it to a canvas and swapping the src to that frame's data URL. No-op if already frozen or not yet loaded. Silently skipped (left animating) if the canvas gets tainted by a cross-origin image without CORS headers.
