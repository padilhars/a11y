(static, constant) recordActivation

Record one activation of the given option id. The server is the sole authority on whether this actually gets persisted (config:: collect_stats_enabled(), re-checked in classes/stats.php regardless of anything the client believes) - this call fires unconditionally whenever amd/src/main.js decides an activation happened; callers that want to skip the network request entirely when collection is known to be off client-side should check that themselves first (see main.js's own `statsEnabled` flag) - purely a network-efficiency choice, never a security boundary.
